# push_swap

An algorithmic C project focused on sorting a stack of integers using a limited set of operations.

## Objective

Generate a sequence of operations that sorts the values while respecting the project rules and minimizing the number of moves.

## Features

- Argument validation and error handling.
- Implementation of the allowed stack operations.
- Sorting algorithm adapted to the project's constraints.
- Handling of edge cases and different input sizes.

## Technologies

- C
- Data structures
- Algorithms and optimization

## Build and Usage

```bash
make
./push_swap 4 2 7 1 3
```

The program outputs the sequence of operations required to sort the stack.

## Technical Highlights

This project involved comparing algorithmic strategies and exploring the trade-offs between algorithmic complexity and the number of operations required to sort a stack.
